# 面向空气质量数据相似性分析的度量学习与城市聚类 - 分析报告

## 1. 项目背景

城市空气质量聚类分析是环境管理和区域联防联控的基础性工作。传统方法使用欧氏距离度量城市间的空气质量差异，但这种各向同性的距离假设忽略了不同污染物维度对聚类结构的差异化贡献。度量学习（Metric Learning）通过从数据中学习最优距离度量矩阵，能够自动发现哪些污染物维度对区分城市空气质量类型更为重要，从而提升聚类质量。本项目以中国31个省会城市2016-2019年的逐小时空气质量数据为基础，构建城市年度特征矩阵，对比NCA和LMNN两种度量学习方法与传统欧氏距离基准在K-means聚类中的效果差异。

## 2. 数据说明

| 项目 | 说明 |
|------|------|
| 数据来源 | 中国环境监测总站（全国城市空气质量实时发布平台） |
| 时间范围 | 2016年1月 - 2019年12月（4年） |
| 城市覆盖 | 31个省会城市及直辖市 |
| 数据粒度 | 逐小时监测数据 |
| 污染物指标 | AQI、PM2.5、PM10、SO2、NO2、CO、O3（6项+综合指数） |
| 特征矩阵 | 124样本 x 23特征（31城市 x 4年） |
| 有效数据标准 | 每种污染物每日有效小时数 >= 18 |

**23个特征构成：**
- 7种污染物年均值（7维）
- 7种污染物标准差（7维）
- 7种污染物最大值（7维）
- 优良天数比例（AQI<=100占比，1维）
- 重污染天数比例（AQI>200占比，1维）

## 3. 方法概述

### 3.1 K-means基准（欧氏距离）

K-means是最常用的划分聚类算法，使用欧氏距离作为样本间的相似度量。在本项目中，K-means随机种子设为42，遍历k=2到8，通过轮廓系数选择最优聚类数。欧氏距离假设所有特征维度等权重，无法体现不同污染物对城市分类的差异化贡献。

### 3.2 NCA（Neighborhood Components Analysis）

NCA是一种基于软最近邻分类目标的度量学习方法。它学习一个线性变换矩阵M，使得变换后空间中最近邻分类的期望准确率最大化。本项目使用scikit-learn实现的NCA，设置max_iter=1000，保持原始23维不降维。NCA的优化使用L-BFGS算法，学习率由内部自动调整。伪标签来自欧氏距离K-means的聚类结果（无监督初始化策略）。

### 3.3 LMNN（Large Margin Nearest Neighbor）

LMNN是一种基于半定规划约束的度量学习方法，目标是最小化同类样本间距同时最大化异类样本间距。本项目使用metric-learn库实现，设置K=3（每个类别考虑3个最近邻）、学习率1e-3、最大迭代1000次。LMNN要求输入有标签数据，因此同样使用欧氏距离聚类结果作为伪标签。

## 4. 核心结果

### 4.1 内部评估指标（最佳k=2时）

| 方法 | 轮廓系数 | DB指数 |
|------|----------|--------|
| 欧氏距离 + K-means | 0.3409 | 1.1609 |
| NCA + K-means | **0.4506** | **0.8292** |
| LMNN + K-means | **0.4463** | 0.8629 |

### 4.2 外部评估指标（以地理分区为真实标签）

| 方法 | ARI | AMI |
|------|-----|-----|
| 欧氏距离 + K-means | 0.1474 | 0.1945 |
| NCA + K-means | 0.1426 | 0.1880 |
| LMNN + K-means | 0.1474 | 0.1945 |

### 4.3 训练时间（5次重复取平均）

| 方法 | 平均时间(秒) | 标准差 |
|------|-------------|--------|
| 欧氏距离 + K-means | 0.406 | 0.771 |
| NCA + K-means | **0.036** | 0.004 |
| LMNN + K-means | 0.400 | 0.038 |

### 4.4 不同k值的轮廓系数对比

| k | 欧氏距离 | NCA | LMNN |
|---|----------|-----|------|
| 2 | 0.3409 | 0.4506 | 0.4463 |
| 3 | 0.2390 | 0.3593 | 0.3242 |
| 4 | 0.2619 | 0.3447 | 0.3137 |
| 5 | 0.2620 | 0.3447 | 0.3182 |
| 6 | 0.2710 | 0.3517 | 0.2918 |
| 7 | 0.2115 | 0.3120 | 0.2973 |
| 8 | 0.2126 | 0.2614 | 0.3065 |

## 5. 关键结论

1. **度量学习显著提升聚类质量**：NCA使轮廓系数从0.3409提升到0.4506（提升32.2%），DB指数从1.1609降低到0.8292（降低28.6%），证明学习到的距离度量优于原始欧氏空间。

2. **NCA综合性能最优**：NCA在聚类质量上表现最佳（轮廓系数最高），且训练时间最短（仅0.036秒），适合作为空气质量聚类的首选度量学习方法。

3. **两种度量学习均一致将城市分为两类**：聚类0（71个样本）包含南方和西南城市（上海、广州、昆明、拉萨等），聚类1（53个样本）包含北方重工业城市（北京、天津、石家庄、太原等），分类结果与地理气候分区高度吻合。

4. **重污染带呈条带状集聚分布**：重污染城市主要集中在华北平原（北京-天津-石家庄-太原-济南-郑州-西安）及西北地区，与冬季燃煤采暖区和重工业布局高度吻合。

5. **LMNN在小样本场景下接近NCA效果**：LMNN（0.4463）与NCA（0.4506）轮廓系数非常接近，但LMNN训练时间约为NCA的11倍，且对参数（K值、学习率）更敏感。

## 7. 方法建议

| 场景 | 推荐方法 | 理由 |
|------|----------|------|
| 快速探索性分析 | 欧氏距离 + K-means | 无需额外训练，结果可解释 |
| 追求最优聚类质量 | **NCA + K-means** | 轮廓系数最高，训练时间最短 |
| 可解释性要求高 | NCA + K-means | 变换矩阵可反映各污染物重要性 |
| 有先验标签信息 | LMNN + K-means | 可融入专家标注的相似性偏好 |
| 样本量<50 | 欧氏距离基准 | NCA/LMNN在小样本上不稳定 |
